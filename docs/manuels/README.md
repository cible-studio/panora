# Manuels d'utilisation Panora — par rôle

Ces manuels sont conçus pour la **formation des équipes CIBLE CI** à l'utilisation de la plateforme Panora. Chaque rôle a son propre manuel autonome.

## À qui ce manuel s'adresse

| Rôle | Manuel | Public |
|---|---|---|
| **Administrateur** | [00-admin.md](00-admin.md) | Direction, chefs de service, super-utilisateurs |
| **Media Planner** | [01-mediaplanner.md](01-mediaplanner.md) | Media planners, chefs de production |
| **Commercial** | [02-commercial.md](02-commercial.md) | Commerciaux terrain, chargés de compte |
| **Comptable** | [03-comptable.md](03-comptable.md) | Comptables, service facturation |
| **Technicien** | [04-technicien.md](04-technicien.md) | Techniciens terrain, afficheurs (PWA mobile) |
| **Client / Annonceur** | [05-client.md](05-client.md) | Annonceurs, agences partenaires (espace en ligne) |

## Comment se former

**Recommandation** : 1 session de 45 min par rôle, avec l'app ouverte devant l'écran. Le manuel sert de fil conducteur.

**Pour l'animateur** :
1. Ouvrir le manuel du rôle concerné
2. Ouvrir Panora dans le rôle correspondant (via un compte de test)
3. Dérouler chaque section, refaire les workflows en direct
4. Encourager les questions à la fin de chaque section

## Conventions dans les manuels

- **En gras** : les libellés exacts affichés dans l'app
- `Encadré` : les noms techniques (champs, boutons, URLs)
- ⚠️ : action à risque ou piège classique
- 💡 : astuce, bonne pratique
- 🔒 : action nécessitant une autorisation admin
